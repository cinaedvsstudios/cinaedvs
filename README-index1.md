# CINAEDVS index1 Olympus Gateway version

This package is an experimental alternate homepage for the CINAEDVS GitHub Pages site.

Upload these files/folders into the root of the existing repo:

- `index1.html`
- `assets/css/index1.css`
- `assets/js/index1.js`
- `assets/img/`

Then preview it at:

`https://cinaedvsstudios.github.io/cinaedvs/index1.html`

The links that currently point to `#link-coming-soon` are placeholders. Replace them with the live Forever Bound, Patreon, Artifex, Organon, Travel App, or other project URLs when they exist.

This version deliberately uses sanitized filenames inside `assets/img/` so spaces and GitHub case sensitivity do not break the images.

# CINAEDVS Studios homepage

This package contains the updated `index.html` carousel homepage for the CINAEDVS GitHub Pages site.

Upload the contents of this folder to the root of the `cinaedvs` repository, so that `index.html`, `assets/`, `robots.txt`, and `sitemap.xml` sit at the top level.

The page opens with the lion logo over the colonnade image. Clicking the lion reveals the card carousel. On desktop, use the side arrows or top navigation. On mobile, swipe between cards.

SEO files included:

- `robots.txt`
- `sitemap.xml`
- canonical URL metadata
- Open Graph metadata
- Twitter card metadata
- Organization schema JSON-LD


Update notes: carousel now wraps from last card back to first, desktop layout is compressed to fit one screen better, entry lion uses the transparent image without a circular frame, and Backroom preview uses a cover-fill background behind the narrow banner.
